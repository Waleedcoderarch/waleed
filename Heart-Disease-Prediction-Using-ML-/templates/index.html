A smarter approach
to cardiac diagnostics

A machine learning pipeline trained on 1,025 validated medical records, engineered to deliver accurate, real-time cardiovascular risk stratification.

01 — Dataset
1,025 Medical Records

Combined and validated clinical data from the UCI Heart Disease repository, applying rigorous preprocessing, feature selection and PCA dimensionality reduction.

02 — Algorithm
Gradient Boosting

Benchmarked against six classification algorithms. Gradient Boosting achieved superior performance, optimised through GridSearchCV and k-fold cross-validation.

03 — Performance
100% Accuracy · 0.003s

The model achieves perfect classification accuracy on the holdout test set, delivering predictions in under three milliseconds — suitable for real-time clinical workflows.

04 — Deployment
Flask · AWS EKS · ArgoCD

Production-deployed on AWS Elastic Kubernetes Service with automated CI/CD via GitHub Actions, GitOps sync through ArgoCD, and live monitoring via Grafana.
